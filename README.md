# Pocket Container

This repository contains the decompiled source of the **PocketLinux** Android application.

- The APK was decompiled using **apktool** (producing smali code, resources, assets, and native libraries).
- An attempt to generate Java source with **jadx** encountered numerous errors, so the repository currently includes the smali output only.
- The original APK is available at:
  - `PocketLinux (1).apk` (uploaded via AntiGem).

## Directory Layout

```
├── AndroidManifest.xml         # Manifest file (decoded)
├── smali/                     # Smali code (decompiled classes)
├── res/                       # Resources (XML, images, layouts)
├── assets/                    # Asset files bundled with the app
├── lib/                       # Native libraries ( .so files )
└── README.md                  # This file
```

## Usage

You can explore the decompiled code directly in this repository. If you need Java source, you may try decompiling the smali files yourself with tools such as **dex2jar** + **JD‑Core** or retry `jadx` with different flags.
